# DNAage Project Overview

## Purpose
This project analyzes DNA methylation data to estimate DNA methylation age and compare it with chronological age.

## Workflow
1. Download GEO sample metadata
2. Preprocess sample information
3. Run R-based methylation modeling
4. Analyze age difference and related variables

## Repository Policy
- Keep source code and analysis scripts in this repository
- Keep raw and large data files out of version control when possible
- Do not commit generated binary artifacts or private/local files
