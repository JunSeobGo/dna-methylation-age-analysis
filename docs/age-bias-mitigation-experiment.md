# 연령 편향 완화 후보 비교 실험

## 결론

8개 학습 코호트 5,541명만 사용한 코호트 단위 중첩 교차검증에서 **연령 밀도 가중치(`age_density`)를 다음 개발 후보로 선정**했습니다. 표준 모델보다 전체 오차와 양쪽 극단 연령대 오차를 모두 줄였고, 사전에 정한 채택 조건도 충족했습니다.

이 결과는 학습 단계의 후보 선택 결과입니다. 기존 `GSE87571`은 이미 표준 모델 평가에 사용한 잠금 외부 검증셋이므로 이번 실험에서 전혀 읽지 않았으며, 새 후보의 외부 성능을 주장하는 데 다시 사용하지 않습니다. 현재 외부 검증이 완료된 모델은 기존 표준 모델뿐입니다.

## 실험 설계

- 데이터: 8개 학습 코호트, 5,541명, 공통 CpG 869개
- 평가: outer·inner loop 모두 코호트 단위로 분리한 중첩 교차검증
- 하이퍼파라미터: 기존 학습 내부 CV에서 실제 선택된 `alpha = 0.05, 0.1, 0.5`; 각 outer 학습 fold에서 lambda 재탐색
- 결측 처리: 각 학습 fold에서 계산한 CpG 중앙값만 검증 fold에 적용
- 가중치 상한: 개별 표본 가중치 5, fold별 평균 가중치 1
- 외부 검증셋 사용: 없음

비교한 후보는 다음과 같습니다.

| 후보 | 설명 |
| --- | --- |
| `standard` | 모든 학습 표본의 가중치가 1인 기준 모델 |
| `age_density` | 학습 fold 안에서 연령 구간 빈도의 역수를 사용한 가중치 |
| `mixed` | 연령 밀도와 코호트 크기 가중치의 기하평균 |
| `calibrated_standard` | 각 outer fold의 inner OOF 예측만으로 학습한 선형 보정 |

채택 조건은 실험 전에 다음과 같이 고정했습니다.

1. 표준 모델 대비 전체 MAE 악화가 0.20년 이내
2. `<20` 또는 `>=80` MAE가 0.50년 이상 개선
3. 최악 코호트 MAE가 증가하지 않음

여러 후보가 통과하면 두 극단 연령대 MAE 평균이 가장 낮은 후보를 선택했습니다.

## 주요 결과

| 후보 | 전체 MAE | R² | `<20` MAE | `>=80` MAE | 최악 코호트 MAE | 채택 조건 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| `standard` | 4.146 | 0.909 | 5.093 | 7.526 | 9.435 | 기준 |
| `age_density` | **3.781** | **0.921** | **3.581** | **5.500** | **7.136** | 통과 |
| `mixed` | 4.070 | 0.912 | 3.973 | 6.612 | 8.683 | 통과 |
| `calibrated_standard` | 4.455 | 0.895 | 5.649 | 9.135 | 10.672 | 실패 |

`age_density`는 표준 모델 대비 전체 MAE를 0.365년, 20세 미만 MAE를 1.512년, 80세 이상 MAE를 2.026년 줄였습니다. 최악 코호트 MAE도 9.435년에서 7.136년으로 감소했습니다. 기존 표준 예측을 다시 계산한 결과와 저장된 기준 예측의 최대 절대 차이는 `5.68e-14`로, 비교 기준이 재현됐습니다.

## 불확실성과 한계

8개 코호트를 단위로 재표집한 paired cluster bootstrap 결과는 다음과 같습니다. 값은 `표준 MAE - 후보 MAE`이므로 양수가 개선을 뜻합니다.

| 구간 | 평균 개선 | 95% 신뢰구간 | 해석 |
| --- | ---: | ---: | --- |
| 전체 | 0.425년 | 0.028~1.037 | 코호트 변동을 고려해도 개선 방향 |
| `<20` | 1.555년 | -0.336~3.602 | 참여 코호트가 3개뿐이라 불확실 |
| `>=80` | 1.922년 | 0.810~2.806 | 개선 방향이 비교적 안정적 |

다음 한계를 함께 해석해야 합니다.

- 평균 예측 편향은 표준 모델 `+0.207년`에서 `age_density` `+1.119년`으로 증가했습니다. 사전 채택 조건에는 포함하지 않았으므로 결과를 보고 기준을 바꾸지는 않았지만, 새 외부 코호트에서 반드시 감시해야 합니다.
- `GSE73103` MAE는 2.307년에서 2.692년으로 0.385년 악화됐습니다. 최악 코호트는 개선됐지만 모든 코호트가 동시에 개선된 것은 아닙니다.
- 20세 미만 개선의 bootstrap 신뢰구간은 0을 포함합니다. 동일 연령대의 독립 코호트가 더 필요합니다.
- 선형 보정 후보는 전체·극단 연령대 성능을 모두 악화시켜 채택하지 않았습니다.
- 내부 중첩 교차검증 결과만으로 실제 배포 성능이나 새로운 조직·플랫폼에서의 일반화를 보장할 수 없습니다.

## 다음 결정
