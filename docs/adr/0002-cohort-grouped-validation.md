# ADR-0002: 코호트 그룹 기반 중첩 교차검증 사용

- 상태: 승인됨
- 결정일: 2026-08-03
- 관련 PR: #17

## 맥락

학습 데이터는 여러 공개 코호트를 결합하며 코호트마다 연령 분포, 모집 조건, 전처리와 표본 수가 다릅니다. 표본 행을 무작위로 나누면 같은 코호트의 기술적 특성이 학습과 평가에 동시에 들어가 일반화 성능이 과대평가될 수 있습니다.

## 고려한 선택지

1. 표본 무작위 K-fold는 구현이 단순하지만 코호트 누수를 막지 못합니다.
2. 단일 train/test 분할은 특정 분할에 결과가 크게 의존합니다.
3. 코호트를 그룹으로 묶은 nested leave-one-cohort-out은 계산량이 크지만 모델 선택과 평가를 분리할 수 있습니다.

## 결정

8개 학습 코호트를 사용한 nested leave-one-cohort-out을 기본 내부 검증으로 사용합니다.

- outer loop는 코호트 하나 전체를 평가 세트로 둡니다.
- inner loop는 남은 코호트만으로 하이퍼파라미터를 선택합니다.
- 결측 대치와 표준화는 각 학습 fold 안에서만 계산합니다.
- 코호트별 및 연령대별 지표를 전체 지표와 함께 보고합니다.

## 결과

행 단위 분할보다 실제 코호트 이동에 가까운 평가를 얻습니다. 코호트 수가 8개라 불확실성이 남고 실행 시간이 증가하지만, 표본 수가 큰 단일 코호트에 의한 낙관 편향을 줄일 수 있습니다.
