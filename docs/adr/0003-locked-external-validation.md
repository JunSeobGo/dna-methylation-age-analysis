# ADR-0003: 외부 검증은 모델 잠금 후 한 번 수행

- 상태: 승인됨
- 결정일: 2026-08-03
- 관련 PR: #21

## 맥락

외부 검증 결과를 반복해서 확인하며 모델·특징·임계값을 수정하면 외부 데이터가 사실상 튜닝 세트가 됩니다. 그러면 보고한 성능은 독립 일반화 성능이 아닙니다.

## 고려한 선택지

1. 매 실험마다 외부 성능을 확인하면 개발은 빠르지만 검증셋 누수가 발생합니다.
2. 외부 데이터를 여러 조각으로 나누면 표본 수와 극단 연령대의 검정력이 감소합니다.
3. 학습 코호트만으로 설정을 고정한 후 명시적 확인 옵션으로 외부 평가를 한 번 수행합니다.

## 결정

세 번째 방식을 사용합니다.

- 모델 설정, CpG 순서, 결측 대치값과 가중치를 학습 데이터로 먼저 잠급니다.
- 외부 bundle 준비 단계에서는 모델 성능을 계산하지 않습니다.
- 외부 평가는 명시적 확인 인자가 있어야 실행됩니다.
- 기존 결과가 있으면 기본적으로 재실행을 중단합니다.
- 한 번 사용한 GSE87571은 새 후보의 독립 검증에 재사용하지 않습니다.

## 결과

GSE87571 결과는 표준 모델의 외부 성능 근거로 유지됩니다. age-density 후보에는 새로운 미사용 코호트가 필요해 데이터 확보 비용이 증가하지만, 후보 선택과 외부 평가의 경계를 보존합니다.
