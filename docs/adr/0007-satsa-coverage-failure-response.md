# ADR-0007: SATSA CpG coverage 미달에 대한 대응

- 상태: 승인됨
- 결정일: 2026-08-11
- 관련 Issue: #30, #43

## 맥락

SATSA `S-BSST1206`의 beta 5개 파일에서 잠근 447명과 869개 모델 CpG를 스트리밍 추출한 결과, 사전 품질 게이트가 실패했습니다.

| 항목 | 값 |
| --- | ---: |
| 모델 CpG | 869개 |
| SATSA에 존재하는 CpG | 610개 (70.20%) |
| 사전 coverage 기준 | 0.95 |
| age-density 후보의 비영 계수 | 377개 |
| 그중 SATSA에 없는 CpG | 108개 |
| 없는 CpG의 비영 계수 절댓값 비중 | 26.4% |

원인은 SATSA 공개 행렬이 450K 전체 probe가 아니라 자체 품질검사 후 남은 250,816개만 제공하기 때문입니다. 표본 연결, 파일 무결성, beta 범위 검사는 모두 통과했으므로 코드나 표본 매핑 문제가 아닙니다.

현재 잠긴 869 CpG 모델 쌍으로는 SATSA에서 어떤 성능도 계산할 수 없는 상태이며, ADR-0004가 정한 "SATSA 검증 통과 전에는 표준 모델을 교체하지 않는다"는 경계가 유지됩니다.

## 고려한 선택지

1. **없는 259개를 학습 중앙값으로 대치하고 그대로 평가한다.** 입력 형식은 맞지만 전체 특징의 30%, 비영 계수 절댓값의 26.4%를 상수로 채우게 됩니다. 예측이 학습 평균 쪽으로 수축하므로 고령층 과소예측 개선을 검증하려는 목적 자체가 무효가 됩니다. 결과가 좋게 나와도 대치 때문인지 모델 때문인지 분리할 수 없습니다.
2. **coverage 기준을 사후에 0.70 수준으로 낮춘다.** 데이터를 본 뒤 기준을 완화하는 것이므로 사전 등록의 의미가 사라집니다. 이후의 모든 판정 기준도 신뢰할 수 없게 됩니다.
3. **SATSA 검증을 수행 불가로 종결하고 표준 모델 유지를 확정한다.** 원칙은 지키지만 age-density 후보가 영구 미검증 상태로 남습니다.
4. **SATSA에 존재하는 610개 CpG로 모델 쌍을 학습 데이터만으로 새로 잠그고 재검증한다.** 특징 목록은 외부 데이터의 *가용성*만으로 결정하고 연령 라벨과 오차는 사용하지 않으므로 결과 누수는 없습니다. 다만 잠금 대상을 새로 정의하는 것이므로 별도 기록과 명명 분리가 필요합니다.

## 결정

1번과 2번을 기각하고 **3번과 4번을 병행**합니다.

### 869 CpG 트랙: 종결

- 869 CpG 잠금 모델 쌍에 대한 SATSA 주 검증은 **수행 불가로 종결**합니다.
- 표준 Elastic Net을 현행 모델로 유지합니다. `age_density` 후보는 이 트랙에서 미검증 상태로 남습니다.
- 같은 데이터에 다른 기준을 적용해 재시도하지 않습니다.
- 기존 잠금 모델, GSE87571 외부 검증 결과, 관련 문서는 변경하지 않습니다.

### 610 CpG 제한 트랙: 신규 개시

별도 모델 쌍으로 재검증하되 다음 조건을 지킵니다.

1. 610 CpG 목록은 **SATSA beta의 존재 여부만으로** 결정합니다. SATSA의 연령 라벨, 예측값, 오차는 목록 결정에 사용하지 않습니다.
2. 목록을 설정 파일로 고정하고 해시로 봉인한 뒤에 재학습을 시작합니다.
3. 재학습과 하이퍼파라미터 선택은 학습 8개 코호트 5,541명만 사용합니다.
4. 판정 기준은 ADR-0006의 네 조건을 **값 변경 없이** 그대로 사용합니다.
5. 제한 모델의 내부 성능을 869 CpG 모델과 직접 비교해 우열을 주장하지 않습니다. 특징 집합이 다르므로 각 트랙 안에서만 비교합니다.
6. SATSA 평가는 제한 모델 쌍에 대해서도 **1회만** 수행합니다. 실패 시 같은 코호트로 재시도하지 않습니다.
7. 산출물과 문서에 `restricted610` 접미사를 붙여 869 트랙과 구분합니다.

### 절차 변경

외부 코호트의 **probe 구성을 후보 모델 잠금 전에 확인**합니다. 이번에는 표본 manifest를 모델 잠금 전에 확인했지만 feature 가용성은 6.74GB를 내려받은 뒤에야 확인했습니다. ADR-0005의 대용량 처리 정책에 이 순서를 보완합니다.

## 결과

**얻는 것**

- 사전 등록한 기준을 결과가 나오지 않는 방향으로도 지켰다는 기록이 남습니다.
- 고령층 편향 개선 후보를 완전히 포기하지 않고, 누수 없는 경로로 재검증할 수 있습니다.
- 실패 원인이 모델이 아니라 외부 코호트의 probe 구성이라는 점을 수치로 분리해 두었습니다.

**감수하는 비용**

- 제한 모델 쌍의 중첩 교차검증과 잠금을 다시 실행해야 합니다.
- 특징 집합이 다른 두 트랙의 결과가 공존하므로 문서에서 혼동될 수 있습니다. 명명 규칙과 이 ADR로 구분합니다.
- 610개만 사용하는 제한 모델의 절대 성능은 869 모델보다 낮을 수 있습니다. 이는 두 트랙을 비교하는 근거가 아니라 제한 트랙 자체의 특성입니다.

**후속 작업**

- 제한 모델 쌍 재잠금과 재검증: #43
- 소아 민감도 분석(`GSE193879`)은 869 트랙과 무관하게 계속 진행할 수 있습니다.
