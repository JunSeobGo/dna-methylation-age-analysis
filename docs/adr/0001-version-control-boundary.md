# ADR-0001: Git에는 코드·명세·문서만 저장

- 상태: 승인됨
- 결정일: 2026-08-03
- 관련 파일: `.gitignore`, `scripts/ci/validate_repository.py`

## 맥락

DNA 메틸화 원본은 수백 MB에서 수 GB이고, 처리 bundle과 모델 산출물은 재실행으로 생성할 수 있습니다. 개인 포트폴리오 초안은 공개 저장소의 분석 재현성과도 직접 관계가 없습니다. 이를 모두 Git에 넣으면 저장소가 커지고 민감 정보나 생성 파일을 잘못 공개할 위험이 커집니다.

## 고려한 선택지

1. 모든 데이터와 결과를 Git에 포함하면 한 번에 내려받을 수 있지만 저장소 용량과 공개 위험이 커집니다.
2. Git LFS를 사용하면 대용량 파일을 버전 관리할 수 있지만 공개 원본의 중복 저장과 LFS 비용·쿼터가 발생합니다.
3. 코드·manifest·문서만 Git에 두고 데이터와 결과를 로컬에서 재생성할 수 있습니다.

## 결정

세 번째 방식을 사용합니다.

- Git 추적: 분석 코드, 다운로드 URL·예상 크기, 코호트 정책, 실행·해석 문서
- Git 제외: `data/raw/`, `data/processed/`, `outputs/`, 대용량 문서
- 로컬 전용: `portfolio-private/`의 개인 회고와 면접용 서술
- CI에서 금지 경로와 대용량 문서 확장자를 검사

## 결과

저장소는 가볍고 공개 가능한 상태를 유지합니다. 대신 사용자는 manifest와 문서를 따라 데이터를 내려받고 산출물을 재생성해야 합니다. 재현성을 위해 입력 URL·크기·해시와 실행 명령을 문서화해야 합니다.
