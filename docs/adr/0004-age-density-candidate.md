# ADR-0004: age-density를 외부 검증 대기 후보로 잠금

- 상태: 승인됨
- 결정일: 2026-08-04
- 관련 PR: #27, #29

## 맥락

표준 Elastic Net은 전체 외부 MAE는 양호했지만 80세 이상에서 과소예측이 컸습니다. 학습 표본을 단순히 늘리는 것만으로는 극단 연령대의 낮은 밀도와 코호트 차이를 해결하지 못했습니다.

## 고려한 선택지

1. 표준 가중치를 유지하면 전체 평균 성능은 안정적이지만 극단 연령 편향이 남습니다.
2. 연령 밀도 역빈도 가중치는 희소 연령대의 영향을 높이지만 평균 편향이 악화될 수 있습니다.
3. 연령·코호트 혼합 가중치는 두 요인을 반영하지만 내부 비교에서 age-density보다 개선이 작았습니다.
4. 사후 선형 보정은 단순하지만 내부 비교에서 오차가 악화됐습니다.

## 결정

학습 코호트 중첩 교차검증에서 사전 조건을 통과한 `age_density`를 다음 외부 검증 후보로 잠급니다. 이 결정은 기존 표준 모델을 즉시 교체한다는 뜻이 아닙니다.

- 가중치 상한과 하이퍼파라미터 격자를 학습 데이터에서 고정합니다.
- 후보 모델 파일과 입력 bundle의 MD5를 기록합니다.
- 외부검증 전까지 상태를 `후보`로 유지합니다.
- 기존 GSE87571이 아닌 새 코호트에서 사전 기준을 평가합니다.

## 결과

극단 연령 개선 가능성을 독립적으로 검증할 수 있는 후보가 생겼습니다. 평균 편향 증가 가능성과 일부 코호트 악화가 남아 있으므로 새 외부 검증을 통과하기 전에는 배포 또는 최종 모델 교체를 주장하지 않습니다.
