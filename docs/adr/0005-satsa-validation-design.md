# ADR-0005: SATSA의 개인·가족 의존성과 대용량 beta 처리 정책

- 상태: 승인됨
- 결정일: 2026-08-04
- 관련 Issue: #28, #30

## 맥락

SATSA는 고령층이 충분한 새 혈액 코호트지만 개인별 반복측정과 쌍둥이 가족 구조를 포함합니다. 공개 beta는 여러 대용량 텍스트 파일로 제공되며, 전체 행렬을 한 번에 메모리에 적재하기 어렵습니다.

## 고려한 선택지

1. 모든 반복측정을 독립 표본으로 사용하면 표본 수는 늘지만 불확실성이 과소평가됩니다.
2. 개인별 한 표본만 선택해도 쌍둥이 가족 간 의존성은 남습니다.
3. 원본 전체를 메모리에 적재하면 구현은 단순하지만 메모리와 재시작 비용이 큽니다.
4. 잠근 표본·CpG만 스트리밍 추출하면 구현 검증이 필요하지만 메모리 사용과 재시작 비용을 줄일 수 있습니다.

## 결정

- 450K 표본에서 개인 IID별 가장 이른 연령 표본 하나만 선택합니다.
- 불확실성 계산은 쌍둥이 가족 TID 단위 paired cluster bootstrap을 사용합니다.
- 표본 manifest를 beta 다운로드와 모델 평가 전에 잠급니다.
- 대용량 beta는 파일별·행 단위로 읽고 잠근 SID와 모델 CpG만 추출합니다.
- 파일 무결성, SID 연결, CpG coverage, 결측률과 beta 범위가 사전 게이트를 통과할 때만 평가 bundle을 만듭니다.

## 결과

반복측정을 독립 표본처럼 취급하는 오류와 대용량 메모리 문제를 줄입니다. 일부 모델 CpG가 SATSA 전처리에서 제거되었을 수 있으므로 품질 게이트 실패 시 외부 성능을 계산하지 않고 다른 코호트를 검토해야 합니다.
