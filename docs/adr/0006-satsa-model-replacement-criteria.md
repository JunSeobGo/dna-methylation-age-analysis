# ADR-0006: SATSA 모델 교체 조건을 결과 확인 전에 고정

- 상태: 승인됨
- 결정일: 2026-08-04
- 관련 Issue: #34

## 맥락

age-density 후보는 내부 중첩 교차검증에서 극단 연령대 오차를 줄였지만 평균 편향이 증가했습니다. SATSA 결과를 본 뒤 유리한 지표만 선택하면 외부 검증의 독립성이 훼손됩니다.

## 고려한 선택지

1. 전체 MAE만 비교하면 간단하지만 후보의 목적인 고령층 개선을 직접 검증하지 못합니다.
2. 80세 이상 MAE만 비교하면 전체 성능과 평균 편향의 악화를 놓칠 수 있습니다.
3. 전체 비열등성, 고령층 개선, 편향 제한과 가족 단위 불확실성을 모두 사전에 요구할 수 있습니다.

## 결정

세 번째 방식을 사용하며 수치 기준은 `config/satsa_evaluation_policy.csv`에 고정합니다.

- 전체 후보 MAE는 표준보다 0.20년 넘게 악화되지 않아야 합니다.
- 80세 이상 후보 MAE는 표준보다 0.50년 이상 개선되어야 합니다.
- 후보의 절대 평균 편향은 표준보다 0.50년 넘게 악화되지 않아야 합니다.
- 80세 이상 `표준 MAE - 후보 MAE`의 TID paired cluster bootstrap 95% 신뢰구간 하한이 0보다 커야 합니다.
- 네 조건을 모두 통과할 때만 표준 모델 교체를 검토합니다.

## 결과

외부 결과에 맞춘 사후 판정 기준 변경을 막고 고령층 개선과 전체 안정성을 동시에 요구합니다. 기준이 엄격해 후보가 일부 지표를 개선해도 교체되지 않을 수 있지만, 그 경우 표준 모델을 유지하고 결과를 민감도 분석으로 보고합니다.
