# 학습 데이터 규모별 학습곡선

## 목적

현재 모델의 성능 제한이 학습 표본 부족에서 비롯되는지 확인하기 위해, 학습 코호트의 사용 비율을 늘려가며 예측 오차 변화를 측정합니다. 이번 분석에는 8개 학습 코호트만 사용하며, 최종 외부 검증셋 `GSE87571`은 모델 선택·학습·학습곡선 계산에 사용하지 않습니다.

## 측정 설계

- 평가 단위: leave-one-cohort-out. 한 번에 코호트 하나를 통째로 평가셋으로 분리합니다.
- 학습 비율: 남은 7개 코호트의 25%, 50%, 75%, 100%를 사용합니다.
- 표본추출: 각 코호트와 연령대(`<20`, `20-39`, `40-59`, `60-79`, `>=80`) 조합 안에서 층화 추출합니다.
- 반복: 25%, 50%, 75%는 각각 5회 반복하고, 결정적인 100% 조건은 1회 실행합니다.
- 모델 설정: 최종 고정 모델의 alpha, lambda, 가중치 방식을 그대로 사용합니다. 비율마다 재튜닝하지 않아 표본 수 효과만 비교합니다.
- 결측치: 각 학습 fold에서 계산한 CpG 중앙값만으로 해당 학습·평가 데이터를 대치합니다.
- 주요 지표: 전체 MAE, RMSE, 80세 이상 MAE, 최악 코호트 MAE입니다.

이 설계는 같은 사람이나 같은 코호트가 학습과 평가에 섞이는 누수를 막습니다. 다만 100% 조건은 반복 추출 변동이 없으므로 표준편차가 0이며, 인접 비율과의 작은 차이는 반복 변동과 함께 해석해야 합니다.

고정 하이퍼파라미터는 동일한 8개 학습 코호트에서 선택됐으므로 이 학습곡선의 절대 MAE는 최종 일반화 성능 추정치가 아니라 표본 수 변화 진단값입니다. 최종 내부 성능 추정에는 중첩 교차검증 결과(MAE 4.146년)를 사용하고, 최종 외부 성능은 잠금 외부 검증 결과(MAE 2.795년)를 별도로 보고합니다.

## 측정 결과

| 사용 비율 | 평균 학습 표본 수 | 전체 MAE 평균 ± 표준편차 | 80세 이상 MAE | 최악 코호트 MAE |
| ---: | ---: | ---: | ---: | ---: |
| 25% | 1,208 | 3.938 ± 0.216년 | 6.829년 | 9.329년 |
| 50% | 2,421 | 3.674 ± 0.043년 | 6.972년 | 9.929년 |
| 75% | 3,630 | 3.675 ± 0.101년 | 7.021년 | 9.866년 |
| 100% | 4,848 | 3.616년 | 7.016년 | 9.897년 |

75%에서 100%로 평균 학습 표본을 약 1,218명 늘렸을 때 전체 MAE 개선은 `0.059년`으로 사전 기준 `0.10년`보다 작았습니다. 80세 이상 MAE 개선도 `0.006년`에 그쳤습니다. 따라서 현재와 같은 분포의 표본을 단순히 더 추가하는 것만으로는 큰 개선을 기대하기 어렵습니다.

100% 조건에서 80세 이상 표본은 203명이었고 평균 잔차는 `-6.279년`으로, 고령층 나이를 체계적으로 낮게 예측했습니다. 가장 취약한 홀드아웃 코호트는 `GSE30870`(MAE 9.897년), 다음은 `GSE36054`(MAE 8.160년)였습니다. 다음 개선 단계는 전체 표본 수 확대보다 고령층 표본의 균형 있는 추가, 두 취약 코호트의 플랫폼·전처리·연령분포 차이 점검, 연령 편향 보정의 학습 내부 검증입니다.

예측 결과 88,656행은 `(사용 비율, 반복, sample_id)` 조합이 모두 고유했으며, 요약 MAE를 예측 원본에서 독립 재계산해 일치함을 확인했습니다. `GSE87571`은 학습곡선 입력과 출력에 포함되지 않았습니다.

## 판정 기준

75%에서 100%로 학습 표본을 늘렸을 때 전체 MAE 개선이 `0.10년` 미만이면 실용적인 포화 구간으로 간주합니다. 이 경우 무조건적인 표본 확대보다 고령층 보강, 코호트 편향 교정, 조직·플랫폼 일치성 개선을 우선합니다. 개선이 `0.10년` 이상이면 동일 조건을 만족하는 독립 코호트 추가가 성능 향상에 도움 될 가능성이 있다고 판단합니다.

이 기준은 절대적인 통계 검정이 아니라 프로젝트 의사결정을 위한 사전 정의 기준입니다. 최종 판단에서는 전체 MAE뿐 아니라 80세 이상 MAE와 최악 코호트 MAE도 함께 확인합니다.
